👁️ VisioMate AI

An intelligent voice assistant for visually impaired people. Speak in English or Tamil and it describes surroundings, reads text, identifies currency, guides you, reminds you of medicines and sends emergency alerts.

View on GitHub How to run

Features

🎙️ Voice assistant

Hands-free control with speech in and speech out. Understands English and Tamil/Tanglish commands.

"help", "what time is it"

🧭 Navigation

Turn-by-turn walking directions spoken aloud, using OpenStreetMap.

"navigate to bus stand"

📦 Object detection

YOLOv8 tells you what is ahead, whether it is left, front or right, and how close.

"what is in front of me"

🆘 Emergency SOS

Sends an alert with a map link to your contacts. A 5 second window lets you cancel false alarms.

"emergency", "kaapathunga"

💵 Currency recognition

Identifies Indian rupee notes and adds up the total.

"what note is this"

💊 Medicine reminder

Set reminders by voice and hear spoken alerts at the right time.

"remind me to take tablet at 8:30 pm"

📖 OCR

Reads printed English and Tamil text aloud from the camera.

"read this text"

How to run

git clone https://github.com/merudula/visiomate-ai.git
cd visiomate-ai
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py --text

Use python main.py for voice mode. Install Tesseract OCR for text reading.

Safety: VisioMate is an assistive aid, not a replacement for a white cane or a guide. Default location is approximate; use a GPS module for reliable navigation and SOS.
